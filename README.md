# Forced Shape Key Transfer

異なるトポロジーのメッシュ間で、参照元のシェイプキー変形を転送するBlenderアドオンです。

## 対応バージョン

- Blender 4.2以降

## インストール

1. Blenderの「編集 > プリファレンス > エクステンション」を開きます。
2. 右上メニューから「ディスクからインストール」を選び、このZIPを指定します。

## 基本操作

1. シェイプキーを持つメッシュを参照元として選択します。
2. `Shift`を押しながら転送先メッシュを最後に選択し、転送先をアクティブにします。
3. オブジェクトデータプロパティ（緑色の三角形）を開きます。
4. 「シェイプキー強制転送」パネルから設定し、実行します。

転送先はアクティブオブジェクトです。パネルの「参照元」を明示指定した場合は、選択中の他のメッシュすべてが転送先になります。

## 設定

### 精度

- **法線の重み** — 候補面の評価に法線の不一致をどれだけ反映するか。転送先頂点が意図しない面へ吸着する場合は上げてください。
- **モディファイア適用後で対応付け** — 頂点数と面数が変わらないモディファイア（アーマチュア、シュリンクラップなど）に限り、評価後の形状で対応付けます。

### 転送距離の制限

距離制限の境界で段差が出ないよう、`距離の減衰` で指定した割合だけ手前から転送量を滑らかにゼロへ落とします。

### 対象と重み付け

名前フィルタ（カンマ区切りのワイルドカード）、全体強度、転送先の頂点グループによるマスクが使えます。

### 後処理

- **スムージング** — 転送後の変位にラプラシアン平滑化を掛け、参照元が粗い場合のカクつきを軽減します。
- **左右対称化** — 転送先ローカルX軸で対になる頂点の変位を平均化します。
