# ToPu Forced Shape Key Transfer

異なるトポロジーのメッシュ間で、参照元のシェイプキー変形を転送する独立型Blenderアドオンです。

## 対応バージョン

- Blender 4.2以降
- Blender Extensions形式

## インストール

1. 配布ZIPは解凍しません。
2. Blenderの「編集 > プリファレンス > エクステンション」を開きます。
3. 右上メニューから「ディスクからインストール」を選び、このZIPを指定します。

Blenderが対応している場合は、ZIPをBlenderウィンドウへドラッグ＆ドロップしてもインストールできます。

## 基本操作

1. シェイプキーを持つメッシュを参照元として選択します。
2. `Shift`を押しながら転送先メッシュを最後に選択し、転送先をアクティブにします。
3. オブジェクトモードにします。
4. オブジェクトデータプロパティ（緑色の三角形）を開きます。
5. 「シェイプキー強制転送」パネルから設定し、実行します。

転送先はアクティブオブジェクトです。必ずメッシュを2つだけ選択してください。
