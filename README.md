# ToPu Forced Shape Key Transfer

異なるトポロジーのメッシュ間で、参照元のシェイプキー変形を転送する独立型Blenderアドオンです。

## 対応バージョン

- Blender 4.2以降
- Blender Extensions形式

## インストール

1. 配布ZIPは解凍しません。
2. Blenderの「編集 > プリファレンス > エクステンション」を開きます。
3. 右上メニューから「ディスクからインストール」を選び、このZIPを指定します。

Blenderが対応している場合は、ZIPをBlenderウィンドウへドラッグ＆ドロップしてもインストールできます。

## 基本操作

1. シェイプキーを持つメッシュを参照元として選択します。
2. `Shift`を押しながら転送先メッシュを最後に選択し、転送先をアクティブにします。
3. オブジェクトモードにします。
4. オブジェクトデータプロパティ（緑色の三角形）を開きます。
5. 「シェイプキー強制転送」パネルから設定し、実行します。

転送先はアクティブオブジェクトです。必ずメッシュを2つだけ選択してください。

## 転送方式

### 最近傍面（推奨）

転送先頂点に最も近い参照元の三角形を検索し、三角形上の位置から3頂点のシェイプキー変位を補間します。参照元を一時的に細分化せず、滑らかで精度の高い結果が得られます。

### 最近傍頂点（旧方式）

転送先頂点ごとに最も近い参照元頂点を検索し、その頂点の変形量をコピーします。元のCM3D2 Converterにあった処理へ近い結果が必要な場合に使用します。

## 主な設定

- 転送先の既存シェイプキーを削除：転送前に転送先の全シェイプキーを削除します。Undo可能です。
- 同名シェイプキーを上書き：既存キーを残す場合、同名キーの座標を更新します。
- 現在値もコピー：相対シェイプキーのValueもコピーします。初期状態ではオフです。
- 変形のないシェイプキーを削除：転送結果がしきい値以下のキーを削除します。別キーの相対基準になっているキーは保持されます。
- 転送距離を制限：離れすぎた転送先頂点へ誤った変形が割り当てられるのを防ぎます。

## 元機能からの再構成内容

元実装はBlender 2.7系API、一時複製オブジェクト、編集モードでの細分化、最近傍頂点検索に依存していました。本アドオンは次のように独立再実装しています。

- 元アドオン、画像、共通モジュールへの依存を除去
- Blender 4.2以降の登録・プロパティ・行列APIへ更新
- 最近傍面のBVH検索と三角形補間を追加
- 元の最近傍頂点方式を互換オプションとして維持
- ワールド変換の異なるオブジェクト間で変位ベクトルを正しく変換
- Relative Keyの階層を保ち、子キーを親キーの転送結果から構築
- 絶対シェイプキーのフレームと評価時間にも対応
- リンク共有された転送先メッシュを自動的にシングルユーザー化
- 日本語UI翻訳を内蔵
